# NÓRDIK — Fashion Landing Page

Static frontend portfolio demo for a minimalist clothing brand, built with **HTML, CSS and JavaScript**.

[Open the published demo](https://full-stack-dev-johncastrosanabria.github.io/nordik-landing/)

## What it demonstrates

- Brand introduction and product catalog.
- Benefits, FAQ and call-to-action sections.
- A single-page frontend presentation.

The entry point is [index.html](index.html). This is a presentation demo; the repository does not provide a commerce backend or payment service.

## Preview locally

Serve the repository with any static web server. For example, with Python installed:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. The published site is hosted on GitHub Pages.
